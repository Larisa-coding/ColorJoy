# ColorJoy

Детская студия раскрашивания. Ребёнок выбирает картинку, рисует кистью по движению пальца или мыши, заливает отдельные области, увеличивает детали и сохраняет работу на этом же устройстве.

Аккаунтов, сервера, рекламы и аналитики нет. Рисунки не уходят в интернет.

Название приложения лежит в одном месте: `src/config.ts`, поле `name`.

## Возможности

- Главный экран: продолжить работу, коллекции, галерея, избранное, случайная раскраска, чистый лист.
- Каталог оригинальных раскрасок с замкнутыми областями. Лицензионные франшизы отмечены «Скоро» и не содержат чужих персонажей.
- Редактор на Canvas: кисть, карандаш, фломастер, акварель, ластик, ведёрко, радуга, спрей, блёстки.
- Режим «внутри контуров» и свободное рисование.
- Палитра больше 60 цветов, свой оттенок, избранные цвета.
- Масштаб, перетаскивание, щипок двумя пальцами.
- Отмена и повтор: один жест — одно действие.
- Автосохранение в IndexedDB, галерея, PNG, избранное.
- Наклейки и фон.
- Похвала без модальных окон.
- Детский режим и родительский раздел с математическим подтверждением.
- PWA: установка на экран и работа без сети после первой загрузки.

## Новая коллекция

1. Добавьте объект в `src/catalog/collections.ts`: `id`, название, описание, группа, возраст, порядок.
2. Если группа новая, добавьте её в тип `Group` в `src/catalog/types.ts` и загрузчик в `src/catalog/loadPage.ts`.
3. Карточки читают каталог сами. Редактор менять не нужно.

Коллекция со статусом `soon` показывается с пометкой «Скоро» и без картинок.

## Новая раскраска

1. Добавьте метаданные в `src/catalog/manifest.ts`: id, название, коллекция, группа, сложность, возраст.
2. Добавьте сцену в `src/catalog/build/index.ts` или в `sceneMakers` / `vehicleMakers` / `moreMakers`.
3. Геометрия группы собирается автоматически в `src/catalog/geom/<группа>.ts`.
4. Запустите `npm test`. Страница без замкнутых областей не попадёт в каталог: `finalize()` выбрасывает ошибку.

Отдельный SVG-файл не обязателен. Контуры — полигоны в коде, из них строятся SVG path и маски Canvas. Так проще проверять попадание точки в область без браузера.

## Требования к областям

Каждая область:

- уникальный `id`;
- не меньше трёх точек;
- площадь не меньше 12;
- путь замыкается (`Z`);
- не копирует чужой персонаж.

Дырки задаются вложенностью: если центроид меньшей фигуры лежит внутри большей, меньшая становится дочерней. Краска родителя не закрывает детей. Чёрные контуры рисуются отдельным слоем поверх цвета.

Для маленьких детей ставьте `very-easy` или `easy`: линии толще, областей меньше. Для старших — `medium` или `detailed`.

Подсветка областей: в родительском разделе включите «Показать области».

## Регионы

`hitTest` выбирает самую маленькую область, внутри которой лежит точка. Ведёрко красит только её. Кисть в режиме контуров на каждой точке заново находит область и обрезает мазок её маской. Если палец переходит в соседнюю часть, маска меняется, и линия продолжается уже там.

Фон — обычная область, чаще всего `sky`. Нажатие на небо красит только небо.

## Кисти

Рисование идёт через Pointer Events: `pointerdown`, `pointermove`, `pointerup`. Между редкими событиями `sampleSegment` ставит промежуточные точки, поэтому быстрый жест не рвётся.

- Кисть — мягкий радиальный мазок.
- Карандаш — тонкие зернистые точки.
- Фломастер — плотный круг.
- Акварель — полупрозрачные мягкие пятна. Это визуальное отличие, не физика воды.
- Ластик стирает только след под пальцем. Галочка «стирать до фона» снимает и заливку.
- Радуга, спрей и блёстки используют тот же жест.

Один законченный жест записывается одним действием истории.

## Заливка

Ведёрко срабатывает на нажатие. Область очищается `destination-out` по своей маске и сразу закрашивается выбранным цветом. Соседние области и чёрные линии не затрагиваются. Линии лежат в SVG поверх Canvas.

## Сохранение

После мазка, заливки, стирания и наклейки сохранение ставится в очередь примерно на 700 мс. Дополнительно оно срабатывает при уходе со страницы и при `visibilitychange`.

В IndexedDB база `colorjoy`, версия схемы 1:

- `drawings` — название, даты, статус, избранное, миниатюра;
- `payloads` — операции, фон, масштаб, инструмент.

В LocalStorage ключ `colorjoy:settings`: звук, похвала, детский режим, избранные картинки и цвета, последняя открытая раскраска.

История хранит операции, а не снимок на каждое движение. Снимки `ImageData` нужны только для быстрой отмены и живут в памяти.

Обновление сайта не чистит IndexedDB. Если схема изменится, поднимите `schemaVersion` в `src/config.ts` и добавьте ветку в открытии базы в `src/storage/db.ts`.

Если место кончилось, статус покажет текст про переполнение. Рисунки из-за ошибки не удаляются.

Экспорт и импорт архива JSON есть в родительском разделе. PNG скачивается из галереи и из редактора. В файл попадают фон, заливка, мазки, наклейки и контуры, без кнопок.

## Где лежат данные

Только в браузере этого устройства. Очистка данных сайта или кнопка «Удалить все рисунки» в родительском разделе стирает их. Смена версии приложения сама этого не делает.

## Vercel

1. Импортируйте репозиторий на vercel.com.
2. Framework Preset: Vite.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Переменные окружения не добавляйте.

`vercel.json` отдаёт все пути в `index.html`, поэтому обновление страницы внутри редактора не даёт 404.

После выкладки откройте сайт, нарисуйте штрих, обновите страницу и проверьте, что штрих на месте. Затем в браузере установите приложение: Chrome предложит установку, Safari — «Поделиться» → «На экран Домой».

## Обновление

Обычный деплой заменяет только файлы сайта. Service worker спросит обновить страницу, когда появится новая версия. IndexedDB при этом остаётся.

Не меняйте имена баз `colorjoy` и ключ `colorjoy:settings`, если хотите сохранить старые рисунки.

## Лицензированные коллекции

В каталоге заранее заведены Мимимишки, Три кота, Барбоскины, Трансформеры, Щенячий патруль, Свинка Пеппа, Леди Баг и Человек-паук. Статус `soon`, картинок нет.

Когда появятся права:

1. Положите собственные разрешённые контуры в сборщик сцен.
2. Добавьте страницы в `manifest.ts` с `collection`, равным id франшизы.
3. Уберите `status: 'soon'` у этой коллекции в `collections.ts`.

Не скачивайте официальные раскраски и не рисуйте узнаваемых чужих героев.
